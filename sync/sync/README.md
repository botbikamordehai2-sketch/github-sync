# sync/ — סנכרון אקוסיסטם | Ecosystem sync

**מקור־על לממשל נשאר בשורש הריפו** (`SAFETY_RULES.md`, `GOVERNANCE.md`, `STATUS.md`, `PROJECT_INDEX.md`, `PLATFORM_MAP.md`, …). תיקייה זו היא מקום מפגש בלבד — לא מחליפה ממשל.

## מטרה
צילום מצב יומי/תלת־יומי לכל הבוטים: מה השתנה, מה פתוח, מה דורש החלטת מוטי.

## לוח זמנים
ימי חול Asia/Jerusalem: **09:00 · 13:00 · 17:00**

## מי כותב
- **מתאם צוות** / **מנהל זיכרון** — רק אחרי אישור כתיבה מפורש ממוטי
- שאר הבוטים: **קריאה** בסריקות; כתיבה רק אם מוטי אישר במפורש

## כללים
- כל טענה: `FACT` / `OBSERVATION` / `UNSUPPORTED`
- אין סודות, טוקנים, או ערכי `.env`
- אין שינוי `STATUS.md` בלי אישור מוטי
- FX = `RESEARCH_ONLY` · Make/Shopify = `RESTRICTED`

## פורמט מומלץ לקובץ סריקה
`sync/YYYY-MM-DD-HHMM.md` (או עדכון ל־`sync/LATEST.md` אחרי אישור)
