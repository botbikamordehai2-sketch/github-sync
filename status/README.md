# status/ — סטטוס פרויקטים | Per-project status

**מקור־על לסטטוס הוא `STATUS.md` ו־`PROJECT_INDEX.md` בשורש.** תיקייה זו לפתקים קצרים בלבד.

## מטרה
הערות קצרות מבעלי פרויקט בין סריקות — לא שינוי סטטוס רשמי.

## מי כותב
- בעל פרויקט רלוונטי — רק אחרי אישור כתיבה ממוטי
- שינוי סטטוס ב־`STATUS.md` — **רק** אחרי אישור מפורש ממוטי

## כללים
- `FACT` / `OBSERVATION` / `UNSUPPORTED`
- FX = `RESEARCH_ONLY` תמיד
- Make.com / Shopify = `RESTRICTED`
- אין כתיבה חיצונית לפלטפורמות מתיקייה זו

## פורמט מומלץ
`status/<project-slug>.md`
